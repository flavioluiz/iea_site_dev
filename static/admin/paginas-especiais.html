Páginas especiais e automáticas

Estas páginas combinam texto editorial, dados estruturados e um template visual. Use o botão indicado para alterações básicas. Uma mudança de cartões, filtros, HTML ou layout precisa de uma solicitação ao mantenedor.

Regra prática: altere o conteúdo pelo painel; peça ajuda quando a mudança for na forma como a página é montada. A prévia mostrará exatamente o que será publicado.

Quando a mudança exige HTML, Hugo ou outro código

Exemplos: criar um tipo novo de cartão, mudar a posição de blocos da Home, alterar filtros, redesenhar uma página automática ou integrar outra fonte de dados.

  1. Abra uma solicitação descrevendo a página.
  2. Explique o resultado desejado e, se possível, anexe uma referência visual.
  3. O mantenedor prepara a alteração de código e envia uma prévia para aprovação antes de publicar.
Solicitar alteração maior

Não é necessário saber qual arquivo HTML ou template deve ser alterado.
