Editor do site IEA/ITA

Você não precisa conhecer Git nem editar código.

  1. Entre com a conta GitHub autorizada.
  2. Escolha o tipo de conteúdo no menu.
  3. Preencha os campos e clique em Salvar.
  4. Quando terminar, mude o estado para Em revisão.
  5. Contas mantenedoras também podem marcar como Pronto e Publicar.
